# Reference

The Reference section is lookup-oriented documentation: the details you come back to when you need exact configuration, supported options, or provider-specific setup. Unlike the tutorials, it is not meant to be read front to back.

<Callout type="info" emoji="📚">
  If you are looking for conceptual explanation or a guided walkthrough, the{" "}
  <a href="/docs/introduction">Introduction</a> and{" "}
  <a href="/docs/tutorials">Tutorials</a> sections are the better starting
  points. The Reference assumes you already know what you are configuring.
</Callout>
